## 1. Purpose and scope

**Purpose:** Find the cause of a significant or repeated problem, fix it, and check the fix worked.

**Scope:** Nonconformities, complaints, audit findings and supplier problems that need action. Log: NEEDS CONFIRMATION.

## 2. Responsibilities

Action owner: NEEDS CONFIRMATION. Effectiveness checker: NEEDS CONFIRMATION.

## 3. Procedure

_Everything under Procedure is a prompt for Marpet to confirm, replace or delete. It is not a statement of how Marpet works. Marpet's use of Tolra is NOT verified._

- Decide whether corrective action is needed: seriousness, cause, repeat risk, similar work elsewhere.
- Find the cause with the people doing the work. Check similar work and similar sites.
- Set action, owner and due date. Changes to instructions, training or risk register (MAR QMS 007) where needed.
- Check later evidence that the action worked. Reopen if it did not. Record sample, period, result and date.
- Close only when containment, disposition, approvals and effectiveness are complete.

## 4. Records

Corrective action log; cause analysis; action plan; effectiveness check.
