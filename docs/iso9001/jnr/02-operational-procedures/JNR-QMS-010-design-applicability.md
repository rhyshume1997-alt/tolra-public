**Purpose and scope.** Decide and record whether JNR carries out any design or development, and so whether the design requirements apply. All work JNR does, including build-to-print work, customer-supplied drawings, JNR-made drawings, CNC programs and fixtures. Decision: NEEDS CONFIRMATION.

**Source drafts adapted.** No Codex procedure exists. Source prompts: Codex #335 (clause 8.3) and #367 (gap M4-01).

## Responsibilities

- John, with an ISO adviser if used: makes the applicability decision. NEEDS CONFIRMATION.
- Workshop lead: reports any design work done in the shop (for example fixtures or programs).

## Procedure (draft)

Short working steps. Only what Tolra does is described as fact. Everything else is a prompt for JNR.

1. List every activity that could count as design or development (for example JNR-made drawings, CNC programs, fixtures, changes to customer drawings). NEEDS CONFIRMATION.
2. For each activity decide: applicable or not. If not applicable, write the reason. Build-to-print work does not automatically remove every design duty. NEEDS CONFIRMATION.
3. If any design is applicable, write a plan with inputs, controls, outputs, reviews, verification, validation and changes. NEEDS CONFIRMATION: this plan is not in the source drafts.
4. Record the decision with the date and approver. Review it when the work changes.
