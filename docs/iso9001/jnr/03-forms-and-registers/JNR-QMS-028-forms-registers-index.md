## Procedure (draft)

Short working steps. Only what Tolra does is described as fact. Everything else is a prompt for JNR.

1. For each form or register, record: reference, title, owner, location (private), current version, approval date and review date. NEEDS CONFIRMATION for the private list.
2. Mark each form as blank (controlled) or completed (record). Completed forms are kept as records.
3. Compare this index with the shop copies every quarter, or at the review date. NEEDS CONFIRMATION.
