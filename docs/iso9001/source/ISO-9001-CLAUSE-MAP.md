# ISO 9001:2015 support map for JNR Engineering

Document ID: JNR-I1-ISO-9001-CLAUSE-MAP | Version: 0.1 draft | Prepared: 4 November 2026

Proposed owner: John (JNR), with Rhys for Tolra technical facts. Owner appointment, approval, effective date and next review: ____ .

Tolra supports JNR Engineering’s quality work. Software and documents cannot make a company certified. JNR is the company that gets audited. This draft is not evidence that JNR follows the process or meets ISO 9001:2015.

## How to read this map

This is a support map, not a certificate or a full copy of the standard. Use JNR’s licensed standard for the exact requirements. Check the 2015 edition with its applicable climate-change amendment when setting context. No JNR audit, live check or IQ/OQ/PQ was done for this map.

**Supported** means a narrow software task has source evidence; it does not mean a whole ISO clause is met. **Partly** means Tolra helps but JNR must add controls. **JNR must do it outside Tolra** means people, physical work or a separate controlled record are needed. No whole clause below is rated Supported: the company’s operation has not been audited.

Main evidence is pinned to `68f89ca7b801a10587ff9b51d6c820462847b65a`. I, R and V are separate unmerged drafts, not shipped features or approved procedures. Database-dependent features must be checked against the installed release. Test files show intended proof, not a test pass in this job.
