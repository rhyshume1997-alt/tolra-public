# Dated evidence

`npm run validate:evidence` writes one new UTC-dated directory per attempt. Keep its summary and logs together with the exact revision tested. A successful result says MAPPED UNIT PASS ONLY. Database, browser, manual IQ/OQ/PQ and Rhys's VSR approval remain separate and unrun by that command.

Only synthetic test output may be committed here. Review any log before publishing. Save completed company-specific reports privately and never include real customers, passwords, provider keys or tokens. Failed runs are evidence too and must not be labelled as passes.
